# LendIT · ระบบยืม-คืนอุปกรณ์ IT

ระบบยืม-คืนอุปกรณ์ IT ภายในองค์กร เก็บข้อมูลอุปกรณ์เป็นรายเครื่อง (รหัสครุภัณฑ์ + Serial Number)
ตั้งแต่ขอยืม อนุมัติ ส่งมอบ รับคืนพร้อมตรวจสภาพ ไปจนถึงส่งซ่อมและตัดจำหน่าย

## ฟีเจอร์หลัก

**ผู้ใช้งาน**
- สมัครด้วยรหัสพนักงาน (รอผู้ดูแลอนุมัติ)
- ขอยืมหลายอุปกรณ์ในคำขอเดียว ค้นหาและกรองตามประเภท
- ติดตามสถานะ นับถอยหลังวันคืน แจ้งเตือนเมื่อใกล้/เลยกำหนด
- ขอขยายเวลายืม ยกเลิกคำขอที่ยังรออนุมัติ

**ผู้ดูแลระบบ**
- อนุมัติพร้อมเลือกเครื่องที่ส่งมอบ แจ้งเครื่องเสียก่อนส่งมอบ (เลือกเครื่องทดแทนอัตโนมัติ)
- รับคืนพร้อมตรวจสภาพทีละเครื่อง (ปกติ / ชำรุด / เสีย / สูญหาย) และรายการรอซ่อม
- ยืมแทนผู้ใช้ที่เคาน์เตอร์ พิมพ์ใบยืม-คืนสำหรับเซ็นรับ
- จัดการอุปกรณ์รายเครื่อง ผู้ใช้ (ระงับ / สิทธิ์ / รีเซ็ตรหัสผ่าน) ประเภท และแผนก
- รายงาน CSV (เปิดด้วย Excel / Power BI) และประวัติการทำงานของผู้ดูแลระบบ

## เทคโนโลยี

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Prisma · MongoDB · NextAuth

## เริ่มใช้งาน (เครื่องตัวเอง)

```bash
npm install
cp .env.example .env      # แล้วใส่ค่า DATABASE_URL และ NEXTAUTH_SECRET
npx prisma db push        # สร้าง collection และ index
npm run db:seed           # (ไม่บังคับ) ข้อมูลตั้งต้น
npm run dev               # http://localhost:3000
```

`npm run dev` จะคอมไพล์ทุกหน้าล่วงหน้าให้หลังเปิดเซิร์ฟเวอร์ (ดู `scripts/dev.mjs`)

## Deploy (Vercel)

1. Import repository นี้ใน Vercel
2. ตั้ง Environment Variables: `DATABASE_URL`, `NEXTAUTH_SECRET` (สุ่มใหม่ ห้ามใช้ค่าเดียวกับเครื่อง dev), `NEXTAUTH_URL` (= URL ของ Vercel)
3. ใน MongoDB Atlas → Network Access อนุญาต `0.0.0.0/0` (Vercel ไม่มี IP ตายตัว)

## สคริปต์ที่มีให้

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npx tsx prisma/migrate-to-units.ts` | แปลงอุปกรณ์แบบนับจำนวนเป็นรายเครื่อง (dry run, เพิ่ม `--apply` เพื่อบันทึก) |
| `npx tsx prisma/seed-mock-equipment.ts` | เพิ่มอุปกรณ์ตัวอย่าง |
| `npx tsx prisma/seed-mock-serials.ts` | ใส่ Serial ตัวอย่างให้เครื่องที่ยังไม่มี |
